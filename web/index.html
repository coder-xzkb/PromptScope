FIELD NOTES / 001

从一次观察开始.

一个小而完整的视觉实验循环。

五分钟开始

  1. 加载 NASA 样例，或上传 JPEG / PNG / WebP。
  2. 在提示词框每行写一组实验，例如 person. helmet. 与 astronaut. helmet.。
  3. 点击运行。首次使用从官方仓库下载权重；CPU 推理需要等待。
  4. 用 A / B 选择器对比实验；调显示阈值无需重新推理。
  5. 导出 JSON / CSV / Markdown 报告，或保存检测框 PNG。

Agent 怎么工作

模板模式用固定规则生成计划，不调用大模型。LLM 模式使用你配置的兼容 Chat Completions API：先生成 2–4 组计划，再调用本地检测工具，最后根据结构化结果生成分析。图像不发送给 LLM。

每次执行有明确预算，最多 4 组 Agent 实验，不包含训练、任意代码执行或无限循环。计划可以先检查，再执行。

连接大模型

在启动服务器的终端设置以下环境变量并重启。API Key 只由服务端读取。

PROMPTSCOPE_LLM_API_KEY=your-key
PROMPTSCOPE_LLM_MODEL=your-model
PROMPTSCOPE_LLM_BASE_URL=https://api.openai.com/v1

兼容服务需要支持 JSON mode；DeepSeek 使用 max_tokens，其他服务使用 max_completion_tokens。本地服务可使用 localhost HTTP 地址。

读懂结果

显示阈值只筛选已保存的候选框（原生推理保留分数 ≥ 0.05）；文本阈值控制生成标签的 token，需要新实验。

空间匹配按 IoU 从高到低一对一匹配，不区分类别。它是框的对应关系，不是对错判断。

模型分数不是校准概率，跨提示词分数也不能直接当作准确性排序。

导入真实结果与标注

结果 JSON 使用归一化 [x1,y1,x2,y2]，坐标范围 0–1。请先选中对应图片。

{"prompt":"person.","model":"external",
 "detections":[{"label":"person",
 "score":0.8,"box":[0.1,0.1,0.8,0.9]}]}

标注评估 JSON：

{"ground_truth":[{"label":"person",
 "box":[0.1,0.1,0.8,0.9]}],
 "label_map":{"astronaut":"person"}}

评估为单图、指定 IoU 下的 all-points AP；不是 COCO mAP。自由文本标签需要显式映射到真值类别。
